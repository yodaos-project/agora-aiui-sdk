## 先认识几个词

| 名称              | 在这里是什么意思                                           |
| ----------------- | ---------------------------------------------------------- |
| AIUI 应用 / Agent | 本地运行的 Ink 应用，包括页面、麦克风和操作按钮。          |
| Voice Agent       | 云端负责听和说的 AI 参与者。                               |
| Pipeline          | 保存好的 AI 配置，包含识别、模型、声音等服务。             |
| Channel           | 频道，可以理解为应用和云端 AI 通话的房间。                 |
| UID               | 房间中每个参与者的身份。本次接入使用字符串账号。           |
| 会话后端          | 你自己的服务，负责准备凭证，以及管理云端 AI 的启动和停止。 |
| WHIP / WebRTC     | SDK 用来建立连接、实时传输音频的方式。                     |

本地应用和云端 AI 是同一频道中的两个参与者。
SDK 负责应用侧的语音连接，你发布的 pipeline 决定 AI 如何回答。
